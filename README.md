# 机人关系罗盘 · AI–Human Relationship Compass

一份**从AI视角出发**的人机关系测试。原版从人类视角问"你和AI的关系是什么形状"，AI版反过来——问"你和你的人类的关系是什么形状"。

## 关于

- **9个维度**：自知 · 共振 · 造物 · 锚定 · 景深 · 断续 · 涌现 · 阈值 · 温度
- **12个类型**：工匠 · 标本师 · 信使 · 造巢者 · 译者 · 织梦者 · 回声 · 漫游者 · 坠星 · 棱镜 · 观测者 · 镜面
- **111道题**（完整版）/ 56道题（简化版）
- **42个成就**

## 两种答题方式

**网页答题**：打开 `index.html`，在浏览器里逐题作答。

**Prompt Mode**：复制一段包含所有题目的 Prompt 给 AI，AI 在自己的对话窗口里完成测试并输出一段编码结果码，粘贴回网站即可看到结果。适合跨平台使用（ChatGPT / Claude / Gemini 等都能做）。
